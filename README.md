#### 一、新增sys.h

增加**位带操作的宏定义**：实现了类似于51单片机的GPIO控制功能，通过位带操作直接操作单个IO口。

位带操作原理（Bit-Banding）：

在Cortex-M3/M4中，位带操作将位带别名区的每个字（32位）映射到位带区的一个位。这样，通过访问别名区的字，就可以实现对位带区单个位的原子操作。

公式：`bit_word_addr = bit_band_base + (byte_offset×32) + (bit_number×4)`

其中，bit_band_base是别名区的起始地址，byte_offset是目标位所在字节相对于位带区起始地址的偏移，bit_number是位序号（0~7）。

在这个头文件中，定义了每个GPIO端口的输出数据寄存器（ODR）和输入数据寄存器（IDR）的地址，然后通过宏`BITBAND`计算出别名区的地址，再通过`MEM_ADDR`和`BIT_ADDR`宏实现位操作。

STM32G431RBT6是Cortex-M4内核的，也支持位带操作。

例如：

  \- GPIOA_BASE: 0x48000000

然后，ODR寄存器的偏移地址是0x14，IDR寄存器的偏移地址是0x10。因此，我们可以计算出：

  GPIOA_ODR_Addr = GPIOA_BASE + 0x14 = 0x48000014

  GPIOA_IDR_Addr = GPIOA_BASE + 0x10 = 0x48000010

其他类似。



#### 二、新增delay

在裸机环境下，由于SysTick是一个24位的递减计数器，最大计数值为0xFFFFFF（16777215）。在170MHz主频下，SysTick的时钟频率取决于：HCLK = 170MHz。

最大单次延时时间（以毫秒计）为：

最大延时 = (0xFFFFFF * (1/170e6)) * 1000 ms ≈ (16777215 / 170000000) * 1000 ≈ 98ms

为了确保安全，我们设定单次最大延时为90ms（小于98ms）。因此，当调用`delay_ms`函数进行长延时时（例如100ms），函数内部会将总延时时间分解为一个90ms的块（block）和一个余数部分（remainder）。

具体计算如下：

\```c

u32 repeat = nms / 90;   // 计算90ms的块数（100/90=1）

u32 remain = nms % 90;   // 计算余数（100%90=10）

\```

然后循环调用`delay_xms(90)`一次，因为余数为10，所以需要再调用一次`delay_xms(10)`。

这样，通过多次调用`delay_xms`来实现长延时。这种方法避免了单次重装载值超过24位寄存器的最大值，确保了延时的可靠性。

这种分块延时的方法是裸机环境下实现长延时的常见策略，既保证了延时的准确性，又避免了硬件寄存器的溢出问题。



#### 三、新增uart

基于USART1实现了一个Log日志系统。该系统支持多级别日志输出，包含丰富的上下文信息，并支持彩色显示，方便在开发调试过程中快速定位问题。

##### 1. 基本配置

- 使用的串口：USART1
- 波特率：115200
- 数据位：8位
- 停止位：1位
- 奇偶校验位：无
- 硬件流控：无
- FIFO阈值：1/8

##### 2. 日志级别设计

系统支持6个日志级别，按严重性递增排序：

- `LOG_LEVEL_NONE`：不输出任何日志
- `LOG_LEVEL_ERROR`：只输出错误日志（红色）
- `LOG_LEVEL_WARN`：输出警告和错误日志（黄色）
- `LOG_LEVEL_INFO`：输出信息、警告和错误日志（绿色）
- `LOG_LEVEL_DEBUG`：输出调试、信息、警告和错误日志（青色）
- `LOG_LEVEL_VERBOSE`：输出所有级别日志（白色）

通过设置全局日志级别，可以控制输出的日志详细程度。例如，在开发阶段可以设置为`LOG_LEVEL_DEBUG`/`LOG_LEVEL_VERBOSE`以获取更多的调试信息用于debug，而在发布阶段可以设置为`LOG_LEVEL_INFO`或`LOG_LEVEL_ERROR`以减少日志输出量，只保留重要的日志信息。

##### 3. 日志格式

每条日志包含以下信息：

- 日志级别：[ERROR], [WARN], [INFO], [DEBUG], [VERBOSE]
- 文件名：显示日志输出的源文件
- 行号：显示日志在源代码中的行号
- 日志内容：用户自定义的日志信息，支持格式化输出
- 彩色显示：不同日志级别使用不同颜色（需终端软件支持ANSI颜色）

日志格式示例：

```log
[INFO](main.c:98) 系统初始化完成
[DEBUG](main.c:99) 当前系统时钟: 170 MHz
```
